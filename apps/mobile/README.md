# @mathgo/mobile

Expo (SDK 57) app with dev builds (not Expo Go) and expo-router. Screens live in `src/app/`.
`android/` and `ios/` are generated by `expo prebuild` and are not committed.

Metro bundles the app, so relative imports here have no `.js` extension. Workspace packages such
as `@mathgo/game-core` are imported from their built `dist/`: run `pnpm build` at the root first.

## Run on an Android phone (USB)

Needs Android Studio's SDK (`ANDROID_HOME`) and JDK 17.

1. On the phone: Settings → About phone → tap "Build number" 7 times, then Settings → System →
   Developer options → turn on **USB debugging**.
2. Connect the phone by USB and accept the "Allow USB debugging?" prompt. `adb devices` should
   list it as `device`.
3. From the repo root:

   ```sh
   pnpm install
   pnpm build
   pnpm --filter @mathgo/mobile android
   ```

   The first run builds and installs the MathGo dev build (several minutes), then starts Metro and
   opens the app.

4. Later, when only JavaScript changed: `pnpm --filter @mathgo/mobile start`, then open MathGo on
   the phone. Over USB, run `adb reverse tcp:8081 tcp:8081` first; over Wi-Fi, the phone and the
   computer must be on the same network.

Rebuild the dev build (step 3) after adding a package with native code or changing `app.json`.

## Hermes determinism check (S1-08)

The Home screen shows "game-core check": the app builds a fixed-seed sample of questions in
Hermes and compares its fingerprint with the one pinned by game-core's Node tests. It must say
**PASS** with engine **Hermes**. The same line goes to the log:

```sh
adb logcat -s ReactNativeJS | grep S1-08
# [S1-08] PASS engine=hermes seed=1592598566 expected=0c4a6ee6 actual=0c4a6ee6
```

## Without USB: EAS cloud build

```sh
npx eas-cli@latest login
npx eas-cli@latest init            # once; adds the EAS project id to app.json
npx eas-cli@latest build --profile development --platform android
```

Open the link or QR code on the phone to install the APK, then run
`pnpm --filter @mathgo/mobile start` and open the app.
